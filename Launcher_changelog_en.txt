BattleCraft Launcher — changelog

12.08.26v13
- The modpack resource pack is now always enabled: the launcher checks it before the game starts and puts it back into the active list if it was disabled or reset after a mod reinstall

12.08.26v12
- The attack indicator is gone from the graphics settings
- Swap offhand, third-person view and advancements are gone from the controls
- Sprint, parkour speed-up and vehicle speed-up are merged into a single binding: change the key once and it works everywhere

12.08.26v11
- Voice chat icons are now always hidden: on the HUD, next to player names and in groups
- Their toggle sat on H together with weapon inspection, so every inspect brought them back. The key is unbound, and the vehicle edit mode was unbound from the same H as well

12.08.26v10
- Missile lock-on for planes, helicopters and armour is now on X by default

12.08.26v9
- Mod settings that must match for everyone are now aligned by the launcher before the game starts: Distant Horizons generation, parkour actions, Truly Dark darkness levels, duplicate weapon HUDs and Forge update checks
- Only those values change, everything else in the configs stays yours: the chosen microphone, graphics tuned to your machine, personal preferences
- Because of this a settings fix reaches players right away, without redownloading the whole modpack

12.08.26v8
- The core game keys joined the controls: movement, jump, sneak, sprint, attack, use, inventory, drop, pick block, swap offhand, chat, command, player list, perspective, screenshot, fullscreen, advancements
- Cleared the pile-up on G, where four actions sat at once: Curios slots moved to the opening bracket, the voice chat menu moved from V to the period key, voice groups were unbound
- Keys with brackets, period, comma, slash, apostrophe and tilde can now be assigned as well
- Entity render distance is maxed out by default
- Subtitles, main hand, biome blend and mipmap levels were removed from the settings

12.08.26v7
- A key bound to two actions at once now turns red, gets bracketed and shows a red mark on the left, the way the game itself does it
- Leaving a vehicle moved to F, interacting with one moved to L
- Vanilla options joined the game settings: mouse sensitivity and inversion, entity render distance, biome blend, mipmap levels, main hand, attack indicator, subtitles, pause on lost focus, toggle sneak and sprint, smooth lighting

12.08.26v6
- Animals and monsters are off by default on a new server: less load and no stray wildlife on a combat map
- The create server button no longer looks broken without the EULA checkbox: it used to be simply unclickable, now the launcher says outright that the Mojang EULA has to be accepted
- In-game music is off by default
- View bobbing is removed from the settings and stays enabled

12.08.26v5
- Parkour front and back flips are off, and so is the landing roll: it fired from the jump key right after a fall and got in the way
- The launcher fixes the parkour settings itself on first install and from the recommended settings button, so there is no need to wait for a modpack update

12.08.26v4
- Controls in the game settings are split into sections: parkour, weapons, vehicles, BattleCraft, comms and other, instead of one long list
- Wall slide moved to X, hanging from a ledge and clinging to a cliff moved to the right mouse button
- Graphics gained field of view, brightness, clouds, entity shadows, view bobbing and auto jump
- A sound section appeared: master volume, music, ambient and weather
- The button showing an assigned key is no longer shifted to the right
- Removed the vanilla hotbar hotkeys: by default they sat on C and X, the very keys used for zoom and dodge roll

12.08.26v3
- Game settings now live in the launcher: graphics (view and simulation distance, framerate cap, GUI scale, quality, particles, windowed mode, vsync) and controls
- Modpack actions can be rebound from the launcher: click a key in the list and press a new one, a mouse button works too. If one key ends up bound to several actions, the launcher says so
- A button restores the recommended layout: lie down on Z, dodge roll on X, zoom on C, ping on mouse button 4, voice on button 5, BattleCraft actions on Alt, climbing on space
- On first launch the game receives ready-made settings: windowed mode and automatic GUI scale, so the picture never opens broken on laptops and high-resolution monitors
- The launcher checks free disk space before the game folder is chosen and before a modpack or server is installed, instead of dying halfway through
- Removed the picture from the sidebar and the icon from the title bar
- The tooltip above the GitHub button is no longer clipped as it appears

12.08.26hotfix
- Manual edits to server.properties are no longer lost: on start the launcher updates only the settings it manages and leaves every other line of the file untouched
- Simulation distance is no longer tied to view distance and is configured separately: by default the server renders 8 chunks and simulates 6, which noticeably lightens the tick
- Server memory now defaults to 4 GB with matching lower and upper bounds, so the heap no longer grows in jumps during play
- Added garbage collector settings for the server and corrected the client ones: fewer pauses while chunks load, and Distant Horizons is no longer at risk of running out of memory
- Forge mod update checks and the spark background profiler are disabled on every start: fewer network calls at launch and less needless work during play

08.08.26
- After an update a BCR.exe.old file could be left next to the launcher: the new build waits for the old one to exit and then deletes the leftover, retrying while the file is still locked, so no update residue remains

05.08.26
- The build info listed Forge 47.4.20 while the launcher installs 47.4.22: the version is now read from the launcher itself and can no longer drift from what it installs
- Checkboxes no longer spill past the panel edge on hover: the growth fits the space reserved for the checkbox, so in the servers tab the outline is neither clipped nor overlapping the next block

03.08.26
- New versioning scheme: instead of numbers like 8.6.6, a version is now its release date - 03.08.26. A second build on the same day adds hotfix or v2 to the date (03.08.26hotfix, 03.08.26v2)
- Nicknames are limited to 16 characters, the Minecraft limit: longer names could not join a server
- Buttons no longer drift or stay enlarged after a click: hover and press animations are separated and always return the button to its original place
- Removed the dotted focus outline that appeared when tabbing across buttons and checkboxes
- In the servers tab, buttons and checkboxes are no longer clipped: the header with the tabs was moved out of the scrolling area and the glow got its own padding
- Text fields no longer jitter while typing and no longer bleed past the panel edge: instead of resizing, the field lights up its border
- Font glyphs in the interface were replaced with vector icons that recolor with the selected theme
- The settings window now closes itself after a full settings reset
- The launcher is now licensed under AGPL-3.0: forks and derivative builds must stay open source and keep the credit to the author

v8.6.6
- Forge updated to 47.4.22, the latest build for Minecraft 1.20.1. The launcher reinstalls Forge on first run; servers created through the launcher install the same version

v8.6.5
- Every launcher animation now runs on a purpose-built engine: instead of dozens of separate WPF animations, all motion is computed from formulas within a single render tick
- The launcher detects the refresh rate of the display it is open on and paces animations to it; the rate is re-checked when the window moves to another monitor or the display mode changes
- The particle burst on button clicks is noticeably lighter on the GPU: it is drawn as a single layer instead of a dozen and a half separate elements

v8.6.4
- Forge installation is more reliable: installer failures are now detected immediately, and the launcher no longer reports "Installation complete" when Forge did not install
- Closing the launcher in any way (including Alt+F4) now stops a running server — previously it could keep running in the background
- Unexpected errors no longer crash the launcher silently: a message is shown and a report is saved to crash-reports
- Resuming a download now completes correctly when the file is already fully downloaded, and truncated server responses trigger a retry

v8.6.3
- Fixed broken Russian labels in settings (the language list and other captions showed garbled characters in 8.6.1—8.6.2)

v8.6.2
- The "Night aurora" and "Theme flow" backgrounds are twice as light on the GPU again: their animations now run in the same tick as the scene renderer, with no extra frame rebuilds
- "Theme flow" now consumes less than the animated pixel scene

v8.6.1
- The "Night aurora" and "Theme flow" backgrounds are now much lighter on the GPU: their animations no longer tick at the monitor refresh rate (on 144 Hz the load dropped almost in half)
- The gradient layers of these backgrounds are cached into textures — less GPU work on weaker machines

v8.6.0
- Two more backgrounds to choose from — four in total now, for every taste:
- "Theme flow" (animated): soft color fields in your theme colors slowly drift and blend into each other in a beautiful gradient
- "Minimal" (static): a calm theme-matched gradient with a subtle accent glow — no animations at all
- All backgrounds are re-tinted live when the color preset changes

v8.5.0
- New static "Night aurora" background: a night sky with aurora ribbons tinted by the theme accent, twinkling stars, a moon and shooting stars over mountain silhouettes
- Background selection in settings: the animated pixel scene or the static aurora — switching cross-fades smoothly
- In static mode the pixel scene is not simulated — lower CPU usage
- The changelog now opens in the interface language: an English version has been added

v8.4.3
- Fixed scrolling in dropdown lists: in 8.4.2 the wheel could fail to scroll the list at all — scrolling is now per-pixel and truly smooth

v8.4.2
- Smooth scrolling inside dropdown lists (presets, language, servers) — the wheel now glides the list with inertia, just like in settings

v8.4.1
- Fixed theme switching: preset selection and manual HEX colors apply again (regression since 8.2.0 — the color animation was silently failing)
- Side menu buttons no longer stick with an offset after being pressed

v8.4.0

- Every preset in the list has two color dots (primary color and accent), so you can see the palette before choosing
- Applying a preset smoothly blends the whole theme: background, buttons, neon glows and even the kite on the pixel scene flow into the new colors
- The saved preset is now highlighted in the list when settings are opened

v8.3.0
- Preset and language menus now use the squircle style like the rest of the launcher: rounded corners, soft shadow, spacing from the field
- Tooltips and context menus (copy/paste) redrawn to match the launcher theme — gray system windows no longer pop up anywhere
- The dropdown arrow smoothly flips when the list opens
- Checkboxes springily grow on hover
- Unified corner radius for buttons, fields and lists — the interface feels more cohesive

v8.2.0
- The color preset list no longer closes while you scroll it with the wheel
- Changing a preset smoothly blends the theme into the new colors instead of switching instantly
- Dropdown lists open with a springy animation, items highlight and shift on hover
- Sliders came alive: they grow on hover and pulse with a neon halo while dragging
- Input fields slightly grow on focus and bounce elastically on every keystroke
- Pop animation when picking a value in any list

v8.1.1
- The offer to install Java when it is missing now works on any Windows language
- The CANCEL button terminates the game together with all child processes — nothing is left hanging in the background
- Downloads without a known size no longer pile up in RAM
- More reliable file copying during server installation and updates
- Terminal errors are always marked with the [ERR] level

v8.1.0
- The interface became noticeably smoother: the animated background and the blob are now computed on a background thread, the window no longer stutters while dragging or during downloads
- Reduced CPU and memory usage
- English language: a switch in settings, full translation of the interface and logs
- Reliable downloads: on a connection drop the file resumes from where it stopped, up to 5 automatic retries, stalled connections are cut off quickly
- When the server port is busy, only the process holding the port is terminated, not all Java applications (a running game is no longer affected)
- Changing the game folder no longer deletes files silently: if the folder is not empty, the launcher asks for confirmation
- Mod and map versions are now stored separately for each server: updating one server no longer hides updates for the others
- Declining a map update no longer marks it as updated — the offer returns on the next start
- Fixed a freeze of dialog windows opened at the same time
- The launcher slimmed down by about 3 MB by removing unused libraries

v8.0.2

- The launcher detects your system version (Windows 11 / 10) and shows it on the boot screen and in the terminal
